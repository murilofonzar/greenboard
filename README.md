# greenboard
Sistema para auxiliar na criação de atividades para o ensino bilingue.


``npm run start:dev``
``docker pull murilofonzar/postgres:15``
``docker compose up --build``

``Login: http://localhost:3000/auth/login ``
``Register aluno: http://localhost:3000/auth/register/student ``
``Register professor: http://localhost:3000/auth/register/professor ``
``Swagger: http://localhost:3000/api/docs ``
``Postman: backend/postman/Greenboard.postman_collection.json ``
